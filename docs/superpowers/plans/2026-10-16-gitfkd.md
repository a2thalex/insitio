# GitFkd Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A self-hosted, invite-only GitHub-style forge with real git clone/push over HTTP, code browsing, commits/diffs, issues, pull requests with merge, stars, profiles and code search.

**Architecture:** Node + TypeScript. A raw `node:http` server sends smart-HTTP git URLs to a `git http-backend` CGI bridge and everything else to a Hono app that renders `hono/jsx` pages server-side. All repository work spawns the system `git` against bare repos; app data lives in SQLite through `node:sqlite`.

**Tech Stack:** Node 25 (app), TypeScript, tsx, Hono 4 + @hono/node-server, node:sqlite, git ≥ 2.38 (`merge-tree --write-tree`), @primer/css, @primer/octicons, marked, sanitize-html, highlight.js, Vitest.

**Spec:** `docs/superpowers/specs/2026-10-16-gitfkd-design.md`, with UI and data-loading decisions from `docs/rea-findings.md`.

## Global Constraints

- Product name: **GitFkd**. Never use GitHub's name, logo or Octocat in the UI.
- Invite-only: the only sign-up path is `/join/:token` with a valid, unused, unexpired invite.
- Private repos return **404** (never 403) to users without read access, in pages and git HTTP.
- Every `git` call uses an argument array (no shell), passes `--end-of-options` before user-supplied refs where git supports it, and rejects refs starting with `-`.
- Every POST form carries `_csrf`; the server rejects POSTs without a matching token (git HTTP routes excluded; they use Basic auth).
- Passwords: scrypt. Personal access tokens: shown once, stored as SHA-256.
- Markdown output is sanitized; user content is never inserted unescaped.
- Data lives under `DATA_DIR` (default `./data`): `gitfkd.db` and `repos/<owner>/<name>.git`.
- Tree pages render the listing without JS; per-entry last commit comes from `/:owner/:repo/tree-commit-info/:ref/*path` (rea-findings §2).
- Tests: `npx vitest run`. Typecheck: `npx tsc --noEmit`.
- Commit after each task with a Conventional Commit subject and the `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` trailer.
